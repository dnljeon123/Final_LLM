# Module 3: Phishing Detection Evaluation Engine
**Owner: Member 3 - ML Researcher**

This directory contains the isolated evaluation framework for the LLM Phishing Detection project. It assesses the performance of the prediction logs generated by Member 2 against the original ground-truth dataset provided by Member 1. 

The engine calculates advanced cybersecurity metrics (including the F2-Score), exports threat-leak misclassifications (False Negatives), and generates comparative visual plots.

## Execution Context
This module expects to be run from the root directory of the `Final_LLM` repository to properly access the shared data and result folders.

### Setup
Ensure you are in the `Final_LLM/` root directory, then install this module's specific dependencies:

pip install -r member3/code/requirements.txt
